# リファクタ候補

## 2026-08-24

### 非同期処理とゲーム状態の所有権を整理する

対象: `web/app.js` の `G`、`AV`、`dailyMode`、`tsumiTimer`、ホーム遷移タイマー。

クリア演出中にホームへ戻って次の問題を開くと、古い `tsumiTimer` が新しい画面へ遅れて作用する状態をブラウザで再現した。今回の修正ではタイマーを画面遷移・問題初期化時にキャンセルしている。今後はゲームセッション単位のID、または状態オブジェクトにタイマーと非同期処理を所有させ、古いセッションの完了処理を無効化できる構造へ整理する。

### 画面遷移とオーバーレイの責務を統合する

対象: `showView`、`goHomeFromHeader`、`openSettings`、`openStats`、`openStore`、各オーバーレイの開閉処理。

デイリー開始カウントダウン中に別画面へ移動すると、カウントダウン完了後にデイリー問題が勝手に開く状態をブラウザで再現した。今回の修正では画面遷移・設定・統計・ストア・説明オーバーレイから共通キャンセル処理を呼ぶようにした。画面遷移、オーバーレイ、タイマー停止を一つの遷移管理にまとめると、同種の取りこぼしを減らせる。

### 文字列更新と動的UI更新を統一する

対象: `fillI18n`、`relocalize`、`updateInfo`、`updateAnswerBar`、`renderStats`、`renderStore`。

言語切替時に動的に生成したARIAラベルだけ旧言語のまま残る問題を確認・修正した。静的属性と動的描画が別々の更新経路を持っているため、翻訳キーから表示文言とアクセシビリティ属性を同時に生成する仕組みへ整理する。
